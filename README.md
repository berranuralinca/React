#  React 
 
Bu repository, React öğrenme sürecimde yaptığım egzersizleri, uygulamaları ve öğrendiğim temel React konularını içermektedir.
 
React öğrenirken teorik bilgileri küçük uygulamalar ve pratikler üzerinden pekiştiriyorum.
 
---
 
## Hedefler
 
Bu çalışma kapsamında:
 
- React'in temel çalışma mantığını öğrenmek
- JSX kullanmak
- Component tabanlı geliştirme yapmak
- Props ve State kavramlarını öğrenmek
- Event handling işlemlerini yönetmek
- Kullanıcı girdilerini yönetmek
- Array ve object state'leri ile çalışmak
- Componentler arası veri akışını anlamak
- React'te yeniden render mantığını kavramak
- Asenkron JavaScript (`async/await`) kullanmak
- React ile chatbot uygulaması geliştirmek
- İlerleyen aşamalarda API, Tailwind CSS ve React Router kullanmak
hedeflenmektedir.
 
---
 
## Yapılanlar
 
###  React Basics
 
React, kullanıcı arayüzleri oluşturmak için kullanılan component tabanlı bir JavaScript kütüphanesidir.
 
React ile temel olarak:
 
- Component oluşturma
- JSX kullanımı
- JavaScript ifadelerini JSX içerisinde kullanma
- Component render etme
- UI'ı küçük parçalara ayırma
konularını öğreniyorum.
 
 
##  Chatbot Project
 
React öğrenme sürecinde geliştirdiğim temel uygulama örneği. Chatbot içerisinde şu konuları uyguladım:
 
- Components
- Props
- State / useState
- onClick / onChange
- Input yönetimi
- Array state & spread operator
- map() & key
- Conditional rendering
- Componentler arası veri aktarımı
- Lifting state up
- async / await
**Component yapısı:**
 
```
App
│
├── ChatInput
│   ├── input
│   ├── onChange
│   └── sendMessage()
│
├── ChatMessages
│   └── map()
│
└── ChatMessage
    ├── user message
    └── robot message
```
